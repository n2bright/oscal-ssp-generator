# OSCAL SSP generator

> Control implementations written as YAML, generated into OSCAL and a readable System Security Plan.

**Status:** 🚧 In progress

## What it does
Uses compliance-trestle to turn YAML control implementations into OSCAL component definitions, then renders a human-readable SSP in Markdown and Word.

## Frameworks and controls
NIST OSCAL, NIST 800-53 Rev 5, FedRAMP Moderate baseline

## Stack
Python, compliance-trestle, OSCAL
